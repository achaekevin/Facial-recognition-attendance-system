# System & Generated Image Assets

This folder contains all image assets utilized across the **Biometric Facial Recognition Attendance & Operations** system, including UI assets, generated African university campus biometric scenes, and responsive multi-device captures.

---

## Asset Directory

### 1. Generated African University Biometric Scenes
- **`campus-entrance-verification.jpg`** (and timestamped original `african_students_biometric_campus_1789131925199.jpg`):
  Cinematic documentary scene showing an African female university student (natural braids, college jacket, backpack) at a wall-mounted biometric face recognition terminal at the Faculty of Engineering & Technology concourse, with students entering lecture halls in the background.
- **`biometric-enrollment-lab.jpg`** (and timestamped original `african_students_enrollment_lab_1789131944715.jpg`):
  Biometric facial enrollment lab scene showing an African male student at a desktop face scanner terminal, with a female student completing facial registration on a tablet beside him.

### 2. Core Frontend System Assets
- **`hero.png`**: Original hero image asset.
- **`favicon.svg`**: Application favicon.
- **`icons.svg`**: SVG sprite sheet for system icons.
- **`react.svg`**: React logo asset.
- **`vite.svg`**: Vite logo asset.

### 3. Responsive Verification Captures
- **`screenshot_desktop_v4.png`**: Final 1920x1080 desktop capture of the live landing page with the biometric scanning HUD and African students background.
- **`screenshot_tablet_v2.png`**: 768x1024 tablet capture demonstrating responsive card centering and high contrast.
- **`screenshot_mobile_v4.png`**: 375x812 mobile capture showing word-wrap protection and mobile contrast gradient.
